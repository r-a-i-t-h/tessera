Web Component Test - simple

This is much simpler than the other example. It doesn't use shadowDom and doesn't move the children.

This is merely styled as a container and the children stay in place

This simpler model is ideal when the custom element is the intended container of its children and it can build around them.

But it can be broken by removing its dynamically appended elements (in this case the title and image)

These child nodes are initially assigned to the unnamed slot on the web component

and are then moved into the correct element.

They can be overwritten by appendChild or innerHTML, but they won't work quite as expected!
