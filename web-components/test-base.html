This encapsulates the wider functionality, including the rather dodgy child node relocation.

It is provided as a base class with only 3 properties/methods to provide in the derived class:

static a = { [attrName]: value => { } } // handlers for attribute values

b() => [ element1, element1children, element2, element2children ] // where the children are arrays, and a blank array denotes the target for the inherited children.

Note: b() return is rendered on each calling of connectedCallback!

c() => { } // any other code to execute within connectedCallback()

You can also use the convenience methods this.d(id?) to create a div element, and this.e(tag, id?) to create any element.

These child nodes are initially assigned to the unnamed slot on the web component

and are then moved into the correct element.

They can be overwritten by appendChild or innerHTML, but they won't work quite as expected!
